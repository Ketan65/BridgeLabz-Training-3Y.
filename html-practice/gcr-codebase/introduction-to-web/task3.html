How Browsers Fetch & Display Web Pages

  1. URL Entry & DNS Resolution: User enters a URL (e.g., www.example.com). The browser queries DNS servers to translate the domain name into an IP address.
  2. Establishing TCP/IP Connection: The browser initiates a TCP handshake (and TLS handshake for HTTPS) with the web server.
  3. Sending HTTP Request: The browser sends an HTTP GET request asking for the requested webpage resource.
  4. Server Processing & Response: The web server processes the request and sends back an HTTP response containing HTML, CSS, JavaScript, and assets.
  5. Parsing DOM & CSSOM: The browser parses HTML to construct the DOM tree and parses CSS to construct the CSSOM tree.
  6. Rendering & Painting: The browser combines DOM and CSSOM into a render tree, calculates layout positions, and paints pixels onto the screen.
